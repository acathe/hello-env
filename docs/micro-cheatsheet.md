# micro 常用快捷键速查（本机配置）

> 本机环境：micro 2.0.14（Debian）+ detectindent 1.1.1，使用 Linux 默认键位，未配置 `bindings.json`。`C-x` 表示 `Ctrl+x`，`M-x` 表示 `Alt+x`（Meta），`S-x` 表示 `Shift+x`。
>
> tmux 会抢占 `C-a` / `C-b`；要原样发给 micro，按 `<prefix> C-a` / `<prefix> C-b`。

---

## 1. 文件

| 操作 | 按键 |
| --- | --- |
| 打开文件（输入路径） | `C-o` |
| 保存 | `C-s` / `F2` |
| 关闭当前文件（未保存时询问）；关闭最后一个后退出 | `C-q` / `F4` / `F10` |

```bash
micro 文件                  # 打开文件
micro 文件:行:列            # 打开并定位
命令 | micro                # 在 micro 中查看标准输入
```

本机打开文件时会自动检测缩进；手动保存会自动创建缺失的父目录并删除行尾空白；重开文件会恢复光标位置和撤销历史。

## 2. 导航与选择

| 操作 | 按键 |
| --- | --- |
| 上 / 下 / 左 / 右 | 方向键 |
| 向左 / 向右一个单词 | `C-Left` / `C-Right`，或 `M-b` / `M-f` |
| 行首（首个非空白与绝对行首间切换）/ 行尾 | `Home` / `End`，或 `M-Left` / `M-Right` |
| 上一个 / 下一个空行（段落） | `M-{` / `M-}` |
| 上 / 下翻一页 | `PageUp` / `PageDown` |
| 文件开头 / 结尾 | `C-Home` / `C-End`，或 `C-Up` / `C-Down` |
| 跳到指定行、列 | `C-l`，输入 `行[:列]` |
| 边移动边选择 | `S-方向键` |
| 向左 / 向右选择一个单词 | `C-S-Left` / `C-S-Right` |
| 选择到行首 / 行尾 | `S-Home` / `S-End`，或 `M-S-Left` / `M-S-Right` |
| 向上 / 向下选择一页 | `S-PageUp` / `S-PageDown` |
| 选择到文件开头 / 结尾 | `C-S-Up` / `C-S-Down` |
| 全选 | `C-a`（tmux 内按 `<prefix> C-a` 转发） |
| 取消选择 | `Esc` |
| 鼠标选择 | 拖拽选择；双击选词；三击选整行 |

---

## 3. 编辑与剪贴板

| 操作 | 按键 |
| --- | --- |
| 复制选区；无选区时复制当前行 | `C-c` |
| 剪切选区；无选区时剪切当前行 | `C-x` |
| 剪切当前行 | `C-k` |
| 粘贴 | `C-v` |
| 重复当前行或选区 | `C-d` |
| 撤销 / 重做 | `C-z` / `C-y` |
| 上移 / 下移当前行或所选多行 | `M-Up` / `M-Down` |
| 删除左侧一个单词 | `M-Backspace` / `M-C-h` |
| 增加 / 减少所选行缩进 | `Tab` / `S-Tab` |
| 切换插入 / 覆盖模式 | `Insert` |
| 注释 / 取消注释当前行或所选行 | `M-/` / `C-/` |
| 兼容终端退格 | `C-h` |

无选区时，`Tab` 会插入缩进或接受补全，`S-Tab` 会减少当前行缩进。

---

## 4. 查找与替换

| 操作 | 按键或命令 |
| --- | --- |
| 正则搜索 | `C-f`，输入后按 `Enter` |
| 字面搜索（不解释正则） | `M-S-f`（Alt+F） |
| 下一个 / 上一个匹配 | 离开搜索输入框后按 `C-n` / `C-p`；输入框内二者为下一条 / 上一条历史 |
| 取消选择并清除搜索高亮 | `Esc` |
| 跳到指定行、列 | `C-l`，输入 `行[:列]` |
| 上一处 / 下一处 diff 改动 | `M-[` / `M-]` |
| 逐个确认正则替换 | `C-e` → `replace '正则' '替换内容'` |
| 逐个确认字面替换 | `C-e` → `replace '文本' '替换内容' -l` |
| 全部正则替换（不逐个确认） | `C-e` → `replaceall '正则' '替换内容'` |

---

## 5. 标签页与分屏

| 操作 | 按键或命令 |
| --- | --- |
| 新建空标签页 | `C-t` |
| 上一个 / 下一个标签页 | `M-,` / `M-.`，或 `C-PageUp` / `C-PageDown` |
| 新建左右分屏 | `C-e` → `vsplit [文件]` |
| 新建上下分屏 | `C-e` → `hsplit [文件]` |
| 在当前标签页的分屏间循环 | `C-w` |
| 在新标签页打开文件 | `C-e` → `tab 文件` |
| 关闭当前分屏或标签页 | `C-q` |
| 在新标签页打开内嵌终端 | `C-e` → `term [命令]` |

> 内嵌终端聚焦时，切换分屏、打开命令栏、关闭终端分别按 `<C-w><C-w>`、`<C-e><C-e>`、`<C-q><C-q>`。

---

## 6. 多光标与宏

| 操作 | 按键 |
| --- | --- |
| 按当前选区添加下一个匹配；无选区时先选当前词 | `M-n` |
| 在上一行 / 下一行添加光标 | `M-S-Up` / `M-S-Down` |
| 在选区覆盖的每行开头添加光标 | `M-m` |
| 在鼠标位置添加光标 | `C-鼠标左键` |
| 跳过当前匹配，继续找下一个 | `M-x` |
| 删除最近添加的光标 | `M-p` |
| 删除全部多光标 | `M-c` / `Esc` |
| 开始 / 停止录制宏 | `C-u` |
| 执行最近录制的宏 | `C-j` |

建立多光标后，移动、输入、删除和粘贴会同时作用于所有光标。

---

## 7. 命令栏、Shell 与帮助

| 功能 | 按键或命令 |
| --- | --- |
| 打开 micro 命令栏（`>`，执行 micro 命令） | `C-e` |
| 打开交互式 Shell 命令栏（`$`，在 micro 界面外执行） | `C-b`（tmux 内按 `<prefix> C-b` 转发） |
| 打开帮助 | `C-g` / `F1` |
| 显示 / 隐藏底部快捷键菜单 | `M-g` |
| 显示 / 隐藏行号标尺 | `C-r` |
| 查看完整默认键位 | `C-e` → `help defaultkeys` |
| 查看命令列表 | `C-e` → `help commands` |
| 查询某个键的绑定 | `C-e` → `showkey Ctrl-s` |
| 后台运行 Shell 命令并查看单行结果 | `C-e` → `run 命令` |

## 如果只先记 5 组

`C-o/C-s/C-q`（打开 / 保存 / 关闭）、`C-c/C-x/C-v`（复制 / 剪切 / 粘贴）、`C-z/C-y`（撤销 / 重做）、`C-f` 后接 `C-n/C-p`（查找）、`C-e/C-g`（命令栏 / 帮助）。
