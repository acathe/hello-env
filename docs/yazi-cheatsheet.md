# Yazi 常用快捷键速查（本机配置）

> 本机环境：Yazi 26.8.15；按键以本机实际配置和该版本默认 keymap 为准。
> `C-x` 表示 Ctrl+x，`S-x` 表示 Shift+x；`g g` 表示依次按 `g`、`g`，不需要同时按。
>
> 本机 `l`、`p`、`F`、`T` 为自定义键，具体行为列在对应章节。

---

## 1. 启动、退出与帮助

| 功能 | 按键 / 命令 |
| --- | --- |
| 通过本机 wrapper 启动；退出时可让 shell 跟随 Yazi 输出的当前目录 | `y [路径]` |
| 直接启动；退出后 shell 目录不变 | `yazi [路径]` |
| 退出并输出当前目录；通过 `y` 启动时，shell 跟随到该目录 | `q` |
| 退出但不输出当前目录；shell 保持原目录 | `Q` |
| 关闭当前标签页；只剩一个标签页时退出 | `C-c` |
| 暂停到 shell；用 `fg` 返回 | `C-z` |
| 查看当前界面的快捷键帮助 | `F1` 或 `~` |

---

## 2. 导航、选择与预览

| 功能 | 按键 / 说明 |
| --- | --- |
| 上一个 / 下一个项目 | `k` / `j` 或 `↑` / `↓` |
| 返回父目录 | `h` 或 `←` |
| 智能进入：目录则进入，文件则只打开当前悬停项（本机自定义） | `l` |
| 仅进入目录，不打开文件 | `→` |
| 目录历史后退 / 前进 | `H` / `L` |
| 跳到列表顶部 / 底部 | `g g` / `G` 或 `Home` / `End` |
| 向上 / 向下半页 | `C-u` / `C-d` |
| 向上 / 向下整页 | `C-b` / `C-f` 或 `PageUp` / `PageDown` |
| 预览内容向上 / 向下滚动 5 个单位 | `K` / `J` |
| 打开悬停项的详细信息（Spot） | `Tab` |
| 最大化 / 还原预览栏可用区域；只扩展区域，不缩放预览内容（本机自定义） | `T` |
| 选择 / 取消选择当前项，并将光标下移 | `Space` |
| 全选 / 反选 | `C-a` / `C-r` |
| 进入连续选择 / 连续取消选择模式 | `v` / `V` |
| 逐层取消查找或过滤、退出连续选择、清除选择或退出递归搜索 | `Esc` 或 `C-[` |
| 用默认程序打开所选项目 | `o` 或 `Enter` |
| 交互选择打开程序 | `O` 或 `S-Enter` |
| 操作范围 | 有选择时作用于所选项；否则作用于当前悬停项 |

---

## 3. 文件操作

| 功能 | 按键 |
| --- | --- |
| 标记为复制 / 剪切 | `y` / `x` |
| 智能粘贴：悬停目录时粘进该目录，否则粘到当前目录；不强制覆盖同名项（本机自定义） | `p` |
| 粘贴到当前目录，并强制覆盖同名项 | `P` |
| 取消复制 / 剪切状态 | `Y` / `X` |
| 为已复制项目创建绝对 / 相对符号链接 | `-` / `_` |
| 为已复制项目创建硬链接 | `C--`（Ctrl+减号） |
| 创建文件；名称以 `/` 结尾时创建目录 | `a` |
| 批量创建文件 | `A` |
| 重命名所选项目 | `r` |
| 移到回收站，可恢复 | `d` |
| 永久删除，不可从回收站恢复 | `D` |
| 显示 / 隐藏点文件 | `.` |
| 输入并执行 shell 命令 | `;` |
| 输入并执行 shell 命令，阻塞等待结束 | `:` |

---

## 4. 过滤、搜索与跳转

| 功能 | 按键 |
| --- | --- |
| 在当前目录列表中过滤 | `f` |
| 连续智能过滤：唯一目录自动进入，提交文件时直接打开（本机自定义） | `F` |
| 从当前位置向后 / 向前查找列表项目 | `/` / `?` |
| 跳到下一个 / 上一个查找匹配项 | `n` / `N` |
| 使用 `fd` 按名称递归搜索 | `s` |
| 使用 `ripgrep` 按内容递归搜索 | `S` |
| 取消正在进行的递归搜索 | `C-s` |
| 使用 `fzf` 跳到文件或目录 | `z` |
| 使用 `zoxide` 跳到目录 | `Z` |
| 跳到 Home / `~/.config` / `~/Downloads` | `g h` / `g c` / `g d` |
| 跳到回收站 / 输入路径交互跳转 | `g t` / `g Space` |
| 跟随当前符号链接 | `g f` |

---

## 5. 复制路径、显示与排序

| 功能 | 按键 / 说明 |
| --- | --- |
| 复制文件路径 / 文件 URL | `c c` / `c C` |
| 复制所在目录路径 / 目录 URL | `c d` / `c D` |
| 复制文件名 / 不含扩展名的文件名 | `c f` / `c n` |
| 列表附加信息：文件大小 / 权限 / 出生时间（依文件系统支持） | `m s` / `m p` / `m b` |
| 列表附加信息：修改时间 / 所有者 / 不显示附加信息 | `m m` / `m o` / `m n` |
| 排序：修改时间 / 出生时间 / 扩展名（各为正序 / 逆序） | `, m` / `, M`；`, b` / `, B`；`, e` / `, E` |
| 排序：字母 / 自然 / 文件大小（各为正序 / 逆序） | `, a` / `, A`；`, n` / `, N`；`, s` / `, S` |
| 随机排序 | `, r` |

---

## 6. 标签页与任务入口

| 功能 | 按键 |
| --- | --- |
| 在当前目录新建标签页 | `t t` |
| 重命名当前标签页 | `t r` |
| 跳到第 1–9 个标签页 | `1`–`9` |
| 上一个 / 下一个标签页 | `[` / `]` |
| 将当前标签页向前 / 向后交换 | `{` / `}` |
| 关闭当前标签页；只剩一个标签页时退出 | `C-c` |
| 打开 / 关闭任务管理器；内部操作按 `F1` 查看 | `w` |

---

## 如果只先记 5 组

`j/k`、`h/l`（导航与进入），`Space`、`o`（选择与打开），`y/x/p`（复制、剪切、智能粘贴），`a/r`、`d/D`（创建、重命名、回收站与永久删除），`q`、`F1`（退出与帮助）。
